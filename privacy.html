Privacy policy

TWF Books VM backup is a private, internal tool of Two Waterfalls Properties, used only by its owner. Last updated 6 November 2026.

What it accesses

It asks Google for one permission only: "See, edit, create and delete only the specific Google Drive files that you use with this app" (drive.file). It can therefore see and change only the folder and files it created itself. It cannot see any other Drive file and has no access to Gmail or any other Google service.

What it does with the data

It uploads the owner's own backup files to that one Drive folder and downloads them again to check that each copy is identical. Nothing is shared with, sold to or shown to anyone else, and nothing is used for advertising, profiling or any other purpose.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where it is kept

In the owner's own Google Drive and on the owner's own server. The access key is stored only on that server.

Withdrawing access

Access can be removed at any time at myaccount.google.com/permissions. Files already in Drive stay there until the owner deletes them.
